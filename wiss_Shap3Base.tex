\begin{abstract}
ピンアレイ型形状提示ディスプレイ（Shape Display）は，物理形状を動的に変形・提示可能なインタフェースとして研究されているが，
多数のアクチュエータの製造コスト，機構的複雑さによるメンテナンス性，および部品の再利用性の低さが大きな課題となっている．
本稿では，主要な伸縮構造をすべて3Dプリンタで造形し，スナップフィット機構を活用することで追加の締結部品（ネジ・ナット等）を不要とした，個別ユニットで使用可能なリニアアクチュエータ「Shap3Base」を提案する．
本手法では，入手性と再利用性に優れる連続回転サーボモータと伸縮距離センサ以外の電子部品・機械部品を極力排除し，ピンセット等のみで容易に組み立て・分解可能なモジュール構造を実現した．
現段階で実現しているCADモデル上での伸縮部の太さ・長さのカスタマイズ性を示すとともに，試作および駆動・センシングについて述べる．
\end{abstract}

\maketitle

\section{はじめに}

デジタル情報を立体形状として物理空間に提示する形状提示ディスプレイは，HCI分野で長年研究されてきた．代表例であるピンアレイ（Pin-Array）方式は，inFORMのように無数のピンを垂直駆動して2.5次元形状を動的に生み出す\cite{inform2013} \cite{shapedisplays_spatial2015} ．
しかし，基盤となるアクチュエータは専用部品や複雑な構造に依存し，効率的な複製やカスタマイズ性，モジュール単位で機能付加・再利用可能な設計基盤は未成熟である．
そこで本研究では，製造容易性・カスタマイズ性・再利用性を兼ね備えた3Dプリントリニアアクチュエータ「Shap3Base」を提案する．
本システムは汎用3Dプリンタとスナップフィット構造により工具レスでの組み立て・解体を可能とし，機能付加や仕様変更に柔軟に対応する．
本稿では，その設計コンセプトと拡張性，今後の課題を報告する．

\section{関連研究}

\subsection{ピンアレイ型ディスプレイの駆動機構}
ピンアレイ型ディスプレイでは，ピンの保持にリードスクリュー（送りねじ）機構が多く用いられる\cite{shapeclip2015}\cite{interaction2023_2p74}\cite{shapeShift2018}．
しかしピンごとに機構を持つため部品点数が増加し，コスト増加や故障率上昇を招く\cite{pinarray_architectures2023}．
inFORM\cite{inform2013} や Elevate\cite{elevate2021} は高い機能性をもつ一方で，複雑な金属加工部品や専用回路基板を採用している．
3Dプリンタでの製造も普及しつつある\cite{shapeclip2015}\cite{interaction2023_2p74}\cite{shape_8x8_display}が多くは単一目的であり，複製や拡張における製造容易性・再利用性探求には余地がある．

\subsection{形状提示でのモジュール化のアプローチ}
ピンアレイ型ディスプレイでは，液晶ディスプレイや可動膜などの機能要素をピンに付加し\cite{shapedisplays_spatial2015}\cite{shapeclip2015}\cite{pinarray_architectures2023}\cite{wiss2025_c20}，
物理形状以外の表現を拡張する試みが広く行われている．
ShapeClipなどで様々なディスプレイで画素的要素を独立ユニットにモジュール化する\cite{shapeclip2015}\cite{interaction2023_2p74}\cite{commutiles2024} ことで高いスケーラビリティが示されているが，
ユニット化の柔軟性を保ちつつ用途に応じた機能要素や駆動パラメータを自由にカスタマイズできる設計基盤は十分でない．

\subsection{3Dプリントによる製造の容易化}
各構造・部品間の結合には，PLA素材の弾性変形を利用した「スナップフィット」構造を多く採用した．
その結果，部品の多くを一括で3Dプリントでき，追加の結合部品(ねじ等)用いず組み立て可能になり，部品発注による開発遅延を排除し，試作を加速する．
また，より強固な結合のために，熱圧入インサートナット用のねじ留め穴も設計した．

\subsection{2段並列送りねじ機構による全長短縮}
従来多用されている1段送りねじ機構\cite{shapeclip2015}\cite{interaction2023_2p74}\cite{shapeShift2018}は収納時の全長が伸長時の半分以上となり，装置の奥行きが大型化する課題があった．
本研究では，独自のネジピッチ・リード角度・ハメ合い公差を検証して決定した3Dプリント製送りねじを採用し，2つの送りねじ機構を内部に並列統合する「2段伸縮機構」を開発した（図2）．
これにより，伸長時の全長が約200mm以上の場合に収納時の全長を伸長時の半分以下に収めることに成功した．
また伸縮部の外径を細くしたい場合等では，簡易な「1段伸縮機構」も選択可能である．

\caption{2段並列送りねじ機構の動作}

\subsection{電子部品の選定と再利用性}
\begin{itemize}
    \item \textbf{駆動モータ}: 
    入手性が高く小型軽量な連続回転サーボモータ（SG90R系）を採用した．
    発生トルクは人間が手で止められる程度で，誤作動時の安全性の観点からも適する．
    \item \textbf{伸縮距離センサ}: 
    専用基板を不要とし再利用性を高めるため，ToF測距センサ（M5Stack用 VL53L1X）を採用した．
    光学式のため，停電や電源断が起きても外部メモリなしで絶対位置（伸縮距離）を再取得できる．
\end{itemize}

\section{カスタマイズ性の検討と試作}
Fusion360（CAD）でのカスタマイズとBambulab製3Dプリンタ（H2S, P1S）によるPLA部品出力で造形適合性を検証し．
以下が可能であることを確認した（図3）．
\begin{enumerate}
    \item \textbf{伸縮段数の変更}: 伸縮距離を重視する2段機構と，断面外形を細くして高密度配置を優先する1段機構の切り替え．
    \item \textbf{パラメータ可変}: 用途に応じた全長，伸縮距離，伸縮部外径の変更．
    \item \textbf{先端アダプタの換装}: 先端に小型ディスプレイや各種センサ，物理UIパーツを結合する共通スナップフィット形状の付加．
\end{enumerate}

\section{制御構成例}
本アクチュエータは汎用インターフェース（モータ：PWM 3線式，センサ：I2C/Grove）を採用する．
プロトタイプではマイコン「M5StickC Plus」，I2C拡張ユニット「Unit PaHub」，ドライバ「8ch Servo Driver Unit」を組み合わせ，4機を個別制御できた．

\section{現在の課題及び考察}
試作動作を通じ，以下の課題が確認された．
\subsection{伸縮距離センサの個体差と測定精度}
ToFセンサ（VL53L1X）は数mm精度で測距できる一方，個体差による数mmの測定ずれが生じる．
起動時等にルックアップテーブルを作成するキャリブレーションが必要である．

\subsection{出力トルクと伸縮速度の限界}
垂直荷重や圧縮には耐性があるが，SG90Rの出力制限により重い物体を持ち上げるトルクや伸縮速度が不足する場合がある．
小型ギアボックスの内蔵や高出力モータへの換装を検討する．

\subsection{アクチュエータ外径と配置密度のトレードオフ}
高密度なピンアレイ配置には，現在の軸太さはやや大きい．これはSG90RモータとToFセンサのサイズに起因する．
超小型化は「製造の容易さ」「低コスト」「再利用性」とトレードオフとなるため，目的に応じた構造分離（1段化など）で対応すべきと考える．

\section{おわりに}
本稿では，製造容易性・カスタマイズ性・再利用性を目的とした3Dプリントリニアアクチュエータ「Shap3Base」を提案した．
伸縮部をPLAの3Dプリントとスナップフィットで構築し，2段並列送りねじ機構により収納長を大幅に短縮した．
市販モータとToFセンサを非破壊で着脱でき，高い再利用性と安全性を確保した．
今後は，性能の定量計測とキャリブレーション手法の確立を進め，視覚提示素子や他センサを統合した新たなメディア装置の応用開発を推進する．
